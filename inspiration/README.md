# Inspiration

Reference material for Estate Studio graphic designs.

Drop things here as you collect them:

- `moodboards/` — screenshots of luxury listing graphics, agency feeds, print ads you want to echo
- `photos/` — candidate property photography (exterior, twilight, interiors, pool, aerial)
- `type/` — font-pairing samples and lettering references
- `palettes/` — color swatches and gradient studies

## Notes on the current direction

- **Type:** Cinzel (Roman inscriptional caps) for titles, a fine script for the locale line,
  Montserrat for spec/label text. Alternate pairings are built into the app's Font Pairing picker.
- **Color:** near-black ground (`#0f1114`), warm brass accent (`#c6a15b` / `#d8b878`), white text.
- **Composition:** hairline inner frame, content anchored low, generous letter-spacing on all caps.

To use a photo from `photos/` in the app, open it with the **Upload your own** control
(the app runs locally, so it can't auto-scan this folder).

## Reference graphics → Design Presets

The finished listing graphics collected here informed the built-in **Design Preset** buttons
(Twilight Warmth, Gallery Muted, Blue Hour, Penthouse Story). Each preset is a distillation of
composition, colour temperature, type feel and spec-row treatment — never a copy of any brand's
logo, wordmark or exact layout.
